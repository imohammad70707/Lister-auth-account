# 🔐 Account Lister

یک ابزار ساده و کاربردی برای **مدیریت و سازمان‌دهی اکانت‌ها** با امکانات کامل برای افزودن، ویرایش، حذف، جستجو و مدیریت Backup.

## ✨ قابلیت‌ها

* ✅ افزودن اکانت
* 📋 نمایش لیست اکانت‌ها
* 🗑️ حذف اکانت
* ✏️ ویرایش اطلاعات اکانت
* 🔎 جستجو بین اکانت‌ها
* 💾 گرفتن Backup
* ♻️ بازیابی Backup

## 🚀 امکانات

این پروژه برای مدیریت راحت‌تر اطلاعات اکانت‌ها طراحی شده و امکان انجام عملیات اصلی مدیریت اطلاعات را در اختیار کاربر قرار می‌دهد.

### مدیریت اکانت‌ها

امکان اضافه کردن اکانت‌های جدید، مشاهده لیست اکانت‌های موجود، ویرایش اطلاعات و حذف اکانت‌ها.

### جستجو

با استفاده از قابلیت جستجو می‌توان به‌سرعت اکانت موردنظر را در میان اطلاعات موجود پیدا کرد.

### Backup & Restore

امکان تهیه نسخه پشتیبان از اطلاعات و بازیابی آن در صورت نیاز.
